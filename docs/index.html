plain-text life admin for your terminal

Tasks, time, and spending — written the way you'd say them.

jasem reads the deadline, duration, amount, and tags from plain language, and keeps it all as Markdown under ~/.jasem/. Zero dependencies.

capture
$ jasem todo "pay rent next friday, high priority, finance"
✓ added #1: pay rent
  priority=high  deadline=2026-09-18  tags=finance

$ jasem track "1h30min code review, work"
✓ tracked #1 1h 30min · code review · today · #work

$ jasem acc "50k lunch with the team, food"
✓ recorded #1 50,000 · lunch with the team · today · #food
$ pipx install jasem View on GitHub
