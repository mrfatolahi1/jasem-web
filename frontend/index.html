What it tracks

Three things, one format.

Everything you capture becomes a row in a markdown table. The CLI and your text editor read the same files, so nothing is ever locked away from you.

Tasks

Named lists, deadlines, priorities, and tags — captured in plain language.

Time

Log what you worked on, then read it back as a report by period or tag.

Spending

Records with tags and periods, summarised the same way as your time.

Your data

Three files in a folder you already own.

No database, no account, no sync. jasem keeps everything under ~/.jasem/ as padded markdown tables you can open, diff, and hand-edit.

  • tasks.mdevery task, plus one file per named list
  • timelog.mdwhat you worked on, and for how long
  • spending.mdwhat you spent, and on what

How it works

Quiet by design.

  • Plain text first. Every entry is a line you can read without jasem installed.
  • The CLI and the API share one source. Write in either; both see the change immediately.
  • Point it anywhere. JASEM_DIR and friends move the whole store to another folder.
  • Jalali and Gregorian. Both calendars are handled natively.

Run the API

One command, no build step.

The Django backend builds jasem's config, stores, and report builders per request. It creates no data of its own.

Your data stays on your machine.
