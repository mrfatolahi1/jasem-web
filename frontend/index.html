$ jasem

plain-text life admin

Tasks, time, and spending — kept as markdown files you own, under ~/.jasem/. No database, no account, no sync.

The jasem CLI Run the API

What it tracks

Tasks

Named lists, deadlines, priorities, and tags — captured in natural language.

Time

Log what you worked on, then read it back as a report by period or tag.

Spending

Records with tags and periods, summarised the same way as your time.

How it works

  • Everything is a line in a human-readable markdown file you can edit by hand.
  • The CLI and this project read and write the same files, so both see changes instantly.
  • JASEM_DIR and friends point it at any directory you like.
  • Jalali and Gregorian dates are both supported.

Run the API

cd backend
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python manage.py runserver 127.0.0.1:8000

Your data stays on your machine.
